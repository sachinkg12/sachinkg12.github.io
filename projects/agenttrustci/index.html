Concept diagram · Tests over authored traces

The problem

An agent can produce a correct final answer while calling a forbidden tool, inventing a value, or taking actions in the wrong order. Output-only tests miss those differences.

How it works

Encode expectations in test cases, replay tool-call traces, and check policy, answer support, and the permitted sequence of actions with deterministic validators.

What is available

A self-contained Java framework and authored regression cases used in talks on agent governance. The associated manuscript is recorded as accepted at ICCA 2026.

Scope and limitations

The authored traces test validator conformance. They do not establish a production safety rate or guarantee the behavior of a live model.
