Memory analysis

HeapLens

Investigate Java and Android heap dumps with a native Rust engine, interactive views, a query language, and source navigation. Available in VS Code, IntelliJ IDEA, and the terminal.

The problem

A large heap dump can show which objects occupy memory without making it easy to investigate why those objects remain reachable or to find the relevant source code.

How it works

A shared Rust engine parses HPROF files and builds the reference graph. The interfaces expose class histograms, dominator trees, reference paths, snapshot comparison, and HeapQL queries. Source navigation connects investigation back to Java code.

What is available

Released as installable developer tools, with a tool paper in the SPLASH/ISSTA 2026 companion proceedings. The paper reports timing and peak memory on dumps up to 14.8 GB.

Scope and limitations

Heap analysis runs locally. Optional AI features send selected context to the configured provider unless a local model is used. Large retained sets are investigation leads, not proof of a memory leak.
