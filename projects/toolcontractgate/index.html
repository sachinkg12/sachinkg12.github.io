The problem

Authentication identifies a caller, but it does not establish that a requested tool, payload, scope, or API version matches the action that was approved.

How it works

Place a validation gateway between agent intent and tool execution. Resolve a versioned contract, validate the requested tool and payload, check caller scope and limits, and return an allow, review, or block decision with a reason.

What is available

An executable gateway, agent runner, and local deployment configuration. The associated manuscript is recorded as accepted at ICCA 2026, with recorded talks demonstrating the design.

Scope and limitations

The demonstration uses stub tool responses. Connecting the checks to a real tool boundary remains an integration task. Passing a contract check does not establish the overall correctness or safety of a workflow.
